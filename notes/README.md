# Learning notes

Beginner-friendly notes written while building tinyinfer. No ML background needed. Each chapter explains the concepts in plain English, walks through the code with real numbers from the model and ends with a self-check quiz.

| # | Chapter | What you'll learn |
|---|---|---|
| 01 | [How an LLM works](01-how-an-llm-works.md) | What a model file actually contains, tokens, the 1,024 numbers per token, why the model scores all 151,936 tokens, tensor shapes, RMSNorm |

More chapters are added as the engine grows.

**How to use these notes:**
1. Read a section, then open the file it talks about and find the lines it explains.
2. Run the commands yourself, and change the inputs to see what happens.
3. Try the quiz at the end **before** opening the answers.
